MINOR

**Every delegated agent now ends its hand-back with one `result-contract` block, and the method keeps it.** The ten delegate types (`drive-gaps`, `drive-skipper`, `drive-adversary`, `drive-bosun`, `drive-converge`, `drive-hand`, `drive-implement`, `drive-mutation`, `drive-slice`, `drive-tasks`) used to hand back a paragraph written a different way each time. Each now ends with a fenced block of thirteen fields, the same in every type: what it changed, which contracts and invariants it checked, which tests it ran, the decisions and assumptions it made, what it left unresolved, and how hard the task was. The session that delegated it appends the block, verbatim, to an append-only `hand-backs.md` beside the slice (`specs/<feature>/slices/<id>/hand-backs.md`; feature-level stages use `specs/<feature>/hand-backs.md`) through `python3 scripts/check-decisions.py --hand-back <dir> <type> <stage>`, which refuses a block with a field wrong and names the field; a delegate that handed back nothing is recorded with `--hand-back-missing`. Either verb takes `--started <instant>`, the instant the `--hand-backs` line names, for a continuation that arrives after its stage's entry closed; an entry answers the stage it names, so a late block closes the finding it was asked for. The shape is `scripts/hand_backs.py` and `docs/result-contract.md`, `commands/drive.md` gains the section *What every delegate hands back*, and `make check-decisions` holds every `hand-backs.md` to the shape, one line per fault. `make benchmark` prints, per slice, how many stages a typed delegate that belongs to them ran handed back a block. A skipper's `unavailable` answer is now an entry in `decisions.md` like any other, and the skipper's own number goes in its block's `change_summary`, never in `decisions`: a PATCH-level correction that rides in this MINOR.

**Catch-up.** Nothing is asked of an existing decision log or demo log: `make check-decisions` reads them exactly as it did, and a slice with no `hand-backs.md` is not refused, because the gate only reads a `hand-backs.md` that is there. Stages that ended before `hand_backs.py` first reached the project's history owe no block, and `--hand-backs` and `make benchmark` say so instead of counting them. `slipwai migrate` brings `scripts/hand_backs.py`, `docs/result-contract.md`, the new `scripts/check-decisions.py`, and the agent and command files that carry the contract, under `delivery/` in a repository that adopted the method, and it re-projects the agent files of a harness you have installed, so nobody runs anything after it. An agent file or command you edited by hand merges like any other file; where a merge leaves a delegate's brief without the *What you hand back* section, copy it from the factory's version.
