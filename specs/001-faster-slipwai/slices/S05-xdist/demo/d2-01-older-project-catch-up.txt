## .slipwai/catch-up.md as migrate wrote it: where the S05 note sits
note starts at char 11182 of 12436 - inside the 1.6.0 entry's **Owes:** paragraph, which starts at char 2356
A project made before this release stays serial: `slipwai migrate` carries a project's own `parallelSafe` and never adds one, and `adopt` writes none. To opt in, add the line `"parallelSafe": true,` to the project's `project.json` once, with its comma, right after the `"target"` line, where `generate` writes it (a mark written twice is serial, because the gate cannot tell which copy is meant, and only the JSON `true` turns it on), and run `make verify` once; set it `false` to turn it off again. Every Python service's `pyproject.toml` and `uv.lock` gain `pytest-xdist`, so where a project has a dependency of its own, dev or not, `slipwai migrate` stops on a conflict in `apps/<service>/uv.lock` (the service's path as `project.json` records it): take either side of that file, run `uv lock --project apps/<service>`, `git add` the lock and commit. That is done once by hand, for each service of such a project.
